# 未完成的现代性 · 互动式课堂报告 V1

这是一个本机离线的 16:9 课堂演示，使用 HTML、CSS 和原生 JavaScript，无后端、无依赖安装、无 CDN。12 幕、39 个讲述状态，配套提纲约 **23分30秒**。主色为黑、米白、灰与红。

## 开始演示

1. 完整解压工程，保持文件夹结构。
2. 双击 `index.html`，用 Chrome、Edge、Firefox 或 Safari 打开。
3. 点击“点击开始”；按 F（或浏览器 F11）进入全屏。macOS 可使用浏览器菜单进入全屏。

更稳妥的本地服务器方式：

```bash
cd unfinished-modernity
python -m http.server 8000
```

随后在本机浏览器打开 `http://localhost:8000`。部分系统使用 `python3 -m http.server 8000`。这个服务器仅提供静态文件，演示不访问外网。若需严格限制仅本机访问，可加 `--bind 127.0.0.1`。

## 现场按键

| 操作 | 效果 |
| --- | --- |
| Space / → | 当前场景下一步，或进入下一场景 |
| ← | 回到上一步；在场景首步时回到上一场景末步 |
| 视频中 Space | 暂停 / 继续视频 |
| 视频中 → / Esc | 结束视频，显示当前幕后续问题 |
| F | 网页全屏开关 |
| H / 右下角 ? | 操作说明和来源 |
| N | 显示 / 隐藏当前讲述提示（默认隐藏） |
| 点击真实图像 | 放大；Esc关闭 |
| 鼠标移向右下角 | 00—11章节跳转 |

场景地址保留为 `#05.2` 这类哈希，可刷新停留在当前状态。全程不靠滚动。舞台按1600×900设计，等比缩放至1920×1080；非16:9屏幕会留黑边。

## 当前视频状态

工程已包含本地《阿珍爱上了阿强》视频：`assets/video/opening.mp4`。文件为 H.264 + AAC、1920×1080，时长约68秒，不依赖网络。

封面按空格或点击后进入独立视频入口页；视频不会自动播放，点击画面中的播放按钮才开始。播放期间 Space 暂停或继续，→ 进入后续问题。结尾按钮仍可回看片尾12秒。

## 工程目录

  index.html

  assets-sources.md

修改主要文案在 `js/content.js`；改版式在 `css/style.css`。本地字库已做课堂文本子集，新增少见汉字时系统中文字体会补字。不要删掉图片文件夹后只带走 HTML。
